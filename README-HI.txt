CLIPNOVA AI — ANDROID PROJECT STARTER

Is ZIP mein Android Studio ka source project aur offline mobile app starter diya gaya hai.

Abhi kya kaam karta hai:
- Android WebView app shell
- Video idea se prompt/scene-plan banana
- 500 original character concept slots
- Video file select karna aur manual publishing checklist

Abhi kya nahi hai:
- Asli AI video rendering
- AI voice generation
- YouTube/Instagram/Facebook/TikTok par auto-publishing
In features ke liye external services, API keys, platform approvals aur backend chahiye. Free tier ki limits ho sakti hain.

APK banane ke liye:
1. Computer par Android Studio install karein.
2. Is folder ko Android Studio mein Open karein.
3. Gradle sync complete hone dein.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) chunein.
5. APK app/build/outputs/apk/debug/ mein milegi.

Note: Is environment mein Android SDK/Gradle build tool available nahi tha, isliye yeh source project ZIP hai, compiled APK nahi. Is ZIP ko Android Studio mein build karna hoga.
